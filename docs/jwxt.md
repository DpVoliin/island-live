# 教务直连（正方）

## 为什么是这个方案

教务登录页几乎都带验证码，硬做"自动登录"既脆弱又危险（还得保存账号密码）。所以改成：
**你在 WebView 里像平时一样登录**，登录后由 App 在**同一个会话**里请求课表接口。

- ✅ 不保存账号密码（本机只存"教务系统网址"）
- ✅ 不用抓包/逆向，验证码、短信、二次验证都不影响
- ✅ 抓到的课表只写进 App 私有目录

## 接口（新正方 jwglxt）

社区适配脚本里长期稳定的事实性约定（本项目代码自研，未复制代码）：

| 用途 | 请求 |
|---|---|
| 读默认学年/学期 | `GET /jwglxt/kbcx/xskbcx_cxXskbcxIndex.html?gnmkdm=N2151` → 页面里 `<select name=xnm>` / `<select name=xqm>` |
| 取课表 | `POST /jwglxt/kbcx/xskbcx_cxXsKb.html`，body `xnm=<学年>&xqm=<学期>` → 返回 `{"kbList":[…]}` |

字段映射（详见 `TimetableJwxt.kt` 注释）：`kcmc`=课程名 · `cdmc`=教室 · `xm`=教师 ·
`xqj`=星期(1–7) · `jc`=节次(`"1-2"`) · `zcd`=周次(`"1-16周(单)"`)。

**两个坑**（都处理了）：
1. `zcd` 里可能还跟着 `(1-2节)`，那不是周次 —— 要按"周"截断后再解析，否则会多出假周次
2. 节次不连续（`"1,3"`）要拆成多门课 —— 本项目模型是"起始节 + 连续节数"

## 隐私与联网（重要）

- **本页是 App 里唯一需要联网的功能**：只在 WebView 里访问**你自己填的教务网址**
- 其余导入方式（Excel / CSV / JSON / ICS）**全部离线**，不联网、不上传
- 因此 README 里"完全离线"的说法已修正为"**默认全离线；只有教务直连会联网**"（manifests 里也就多了 `INTERNET`）
- 教务系统很多还是 `http://`，所以 manifest 开了 `usesCleartextTraffic` —— 仅为了能打开这些站点

## 通用模式：解析当前页面的表格（强智 / 青果 / URP / 老正方）

强智（jsxsd）这类系统**没有 JSON 接口**，课表页是 HTML 网格。猜接口又脆又白费 ——
所以第二种模式改成：**你把课表页打开，我直接解析你正在看的这张页面**。

做法（`JwxtActivity.SCRIPT_TABLE`，仍在你的 WebView 会话里跑，不额外联网）：

1. 遍历页面所有 `<table>`：表头里"星期列"最多的那个判为课表（找不到就给明确提示，不乱猜）
2. 表头认列 → 列号 → 星期（`周一`/`星期一`/`周1` 都认）
3. 每行第 0 列找节次数字（`1-2节`/`第3,4节` → `1-2`/`3-4`）
4. 单元格拆成多块（优先 `div/p/span`，兼容强智的 `.kbcontent`）→ 按行拆分：
   第一行=课程名；含「周」的行=周次；含 教/楼/室/馆/机房 的行=教室；剩下 ≤12 字且无数字的行=教师
5. 结果**用正方的字段名**（`kcmc/cdmc/xm/xqj/jc/zcd`）回传 → Kotlin 侧一套解析逻辑通吃

> 提取脚本在本地用**假 DOM（强智风格表格）**跑过：6 门课全部正确抽出，含 `1-16周(单)`、`1-8周(双)`。
> 换学校只需看预览对不对；不对就把课表页截图发我，我针对那个页面改规则。

## 实践课缺失（v0.12.2 修复）

正方把课程分两个数组返回：

- `kbList` —— **理论课**（之前只读了这个）
- `sjkList` —— **实践 / 实验环节**（实习、课程设计、实验课等）

只读 `kbList` 会导致实践课整批消失。v0.12.2 起两个数组合并解析，同一套字段映射
（`kcmc` / `cdmc` / `xm` / `xqj` / `jc` / `zcd`）。

**如果导入后仍然缺课**：用教务页的「**复制原始**」按钮把原始返回粘出来 —— 缺课必须靠真实
数据定位（周次写法的变体太多，猜不出来）。最常见的原因是「现在是第几周」填错导致
整表周次错位，用侧栏「周次修正」按教务显示的**教学周**对齐即可。
