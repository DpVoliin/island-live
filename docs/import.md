# 导入课表（v0.2）

> 实现：`sample-timetable/.../TimetableCsv.kt`（解析）· `TimetableStore.kt`（落盘）·
> `TimetableModel.kt`（模型 + 周次）· `ImportActivity.kt`（界面）

## 两条原则

1. **只在本机解析**：文件读进来 → 解析 → 写进 app 私有目录（`filesDir/timetable.json`）。**不联网、不上传**。
   课表是隐私数据，导入过程不该经过任何服务器。
2. **导入格式只是"适配器"**：所有格式最终都产出同一个 `Timetable`（课程列表 + 节次表 + 表头 + 学期起始日），
   存储与界面完全不知道数据是从哪来的。所以新增格式 = 新增一个解析函数，**不动 UI、不动存储**。

## v0.2.0 已支持：CSV / TXT（两种形态自动识别）

### A. 一行一门课（推荐，能写清周次）

```csv
课程名,教师,教室,星期,开始节次,节数,周次
高等数学,张建国,3教305,周一,1,2,1-16
数字电子技术实验,赵晓东,实验楼B204,周二,6,3,1-8单
```

- 表头**可写可不写**；写了就按关键词认列（课程/教师/教室/星期/开始节次/节数/周次），**列顺序随便调**
- 分不清「星期」和「周次」时：含"星期/周几"的列是星期，含"周次/周数/上课周"的是周次
- 分隔符自动识别：`,` `;` `\t` `，`

### B. 网格（直接从 Excel/WPS 课表里框选复制 → 存成 txt）

```
节次	周一	周二	周三
1	高等数学@3教305
2	高等数学@3教305	线性代数@3教207
```

- 首列是节次、后面若干列是星期（无表头时按"第 2 列起 = 周一、周二…"排）
- **同一格往下重复或留空**（合并单元格复制出来的样子）→ 自动并成**连堂课**（span 累加）
- 单元格写法：`课程名@教室` / `课程名(教室)` / `课程名 / 教室`

### v0.2.2 起支持：Excel **.xlsx**（自研最小读取器）

实现：`TimetableXlsx.kt` —— **不引 POI / FastExcel**（那是几十 MB 的解析框架，移动端不划算，
还多一份许可要背）。我们只做"把表读成文本网格"这一件事。

xlsx 本质是 **zip + xml**：共享字符串在 `xl/sharedStrings.xml`，单元格在 `xl/worksheets/sheetN.xml`，
每个单元格形如 `<c r="A1" t="s"><v>5</v></c>`（`t="s"` 表示 `<v>` 是共享字符串下标）。

**关键设计**：读出来后**转成 TSV，再交给 `TimetableCsv`** ——
两种表格形态、表头关键词识别、周次语法、星期写法**全部复用**，一行都不重复实现。

| 细节 | 处理方式 |
|---|---|
| 选工作表 | 优先 `workbook.xml` + `_rels` 指定的**第一张**；拿不到就按 sheet 序号排序取第一张（注意 sheet10 不能排在 sheet2 前） |
| **合并单元格** | **无需特殊处理**：xlsx 只在合并区左上角存值，其余格子在 XML 里不存在 → 转 TSV 就是空格子 → 网格解析本来就把"下一行同列为空"当作上一门课的延续 → **自动并成连堂课** |
| 富文本 | `<si><r><t>…</t></r><r><t>…</t></r></si>` 会拼接 |
| 公式 | 取缓存结果（`<v>`） |
| 空行/空列 | 按单元格引用（`C7`）定位行列，**不会错位** |
| 老版 `.xls` | 明确提示"请另存为 .xlsx 或 .csv"（BIFF 二进制不在支持范围，靠 `D0 CF 11 E0` 头识别） |
| 加密/受保护工作簿 | 给明确报错而不是崩 |
| 内存 | 只解出需要的几个 xml，图片/主题一概不读 |

模板：`tools/课表模板-一行一门课.xlsx`（行式）与 `tools/课表模板-网格.xlsx`（**带合并单元格**，
专门用来验证"连堂课自动合并"这条路径）。

## 字段细节

| 字段 | 接受写法 |
|---|---|
| 星期 | `周一` `星期一` `礼拜一` `1` `一`（也认 `mon` 等英文缩写） |
| 周次 | `1-16` `1,3,5` `1-16单` `1-16双` `3-18(单)`；**留空 = 每周** |
| 开始节次 | 正整数（1 起） |
| 节数 | 正整数，默认 1；超出内置节次表会给警告并截断 |
| 编码 | UTF-8 与 **GBK**（Excel 中文"另存为 CSV"）自动识别 |

### 周次与学期

导入界面会问一句「**现在是第几周**」，用它反推学期起始日（`termStart = 本周一 − (周次−1)×7`）。
之后 `DemoTimetable.currentWeek` 由日期推算，课表**按周过滤**（单周课、前 8 周结课的课会自然消失）。

## 存储格式

`filesDir/timetable.json`（用平台自带 `org.json`，**不引第三方依赖**）：

```json
{ "formatVersion": 1, "source": "csv", "termStartDate": "2026-09-07", "importedAt": 1757...,
  "dayLabels": ["周一","周二","周三","周四","周五"],
  "periods": [{"index": 1, "start": "08:00", "end": "08:40"}],
  "courses": [{"id":"csv-1a2b","name":"高等数学","teacher":"张建国","room":"3教305",
               "day":1,"startPeriod":1,"span":2,"weeks":"1-16","color":-11559040}] }
```

`weeks` 存的是**紧凑字符串**（`1-16单`），和 CSV 里写的一样 —— 人可读、可手改、解析器同一份。

## v0.4 起支持：JSON（小爱课程表众包脚本 / 课表 App 导出）

实现：`TimetableJson.kt`，**零第三方依赖**（用系统自带 `org.json`）。

为什么优先做这条：学校教务系统一改版，改的是**社区维护的脚本**，不是我们的代码；
而脚本输出格式稳定，所以这是覆盖面最广、维护成本最低的一条导入路。

### 认得的写法（宁多认几种，也不让用户去改 JSON）

| 字段 | 兼容写法 |
|---|---|
| 课程名 | `name` / `courseName` / `course` / `title` / `课程名` |
| 教师 | `teacher` / `teacherName` / `老师` / `任课教师` |
| 教室 | `position` / `room` / `location` / `classroom` / `教室` / `地点` |
| 星期 | `1`…`7`（`0` 按周日）、`"周一"`、`"Monday"` |
| 节次 | `[1,2]` / `"1-2"` / `1` / `startSection`+`endSection` |
| 周次 | `[1,2,3]` / `"1-16单"` / `"1,3,5"`；缺省＝每周 |

- 顶层可以是数组 `[{…}]`，也可以是对象 `{courses:[…]}` / `{data:[…]}` —— 会自动往里找"装着课程的数组"
- 节次不连续（如 `[1,3]`）会**拆成两门课并提示**（本项目模型是"起始节 + 连续节数"）
- 两个入口：**粘贴**（导入页「方式三」输入框，可点「填入示例」看格式）或**直接选 .json 文件**（按内容分派，不看后缀）
- 粘贴脚本**源码**会明确报"不是合法 JSON，请粘贴脚本运行后的输出"，而不是含糊的解析失败

> 复用：周次字符串交给 `WeekSet.parse`，星期交给 `TimetableCsv.parseDay`，配色用 `TimetableCsv.colorFor`
> —— 新增一种导入格式不需要重写任何"格式无关"的逻辑。

## v0.5 起支持：ICS 日历（自研最小解析，**不需要 biweekly**）

实现：`TimetableIcs.kt`。原计划引 `biweekly`(BSD-3)，但课表只需要 iCalendar 的一小块，
自己写更可控 —— **继续保持零第三方依赖**。

| 项 | 支持情况 |
|---|---|
| 折行续行（75 字符换行） | ✅ 先还原再解析 |
| `DTSTART` / `DTEND` | ✅ 含 `Z`(UTC) 与 `TZID=…`，统一换算成本地时间 |
| `RRULE` | ✅ `FREQ=WEEKLY` + `INTERVAL` / `COUNT` / `UNTIL` / `BYDAY`（多个星期几会拆成多门课） |
| `EXDATE` | ✅ 排除对应周次 |
| `SUMMARY` 写成 `课程@教室` | ✅ 自动拆开 |
| `VALARM` 里的 `DTSTART` | ✅ 隔离（否则提醒时间会污染上课时间） |
| 全天事件（只有日期没时间） | ⛔ 跳过并提示 |
| `FREQ=DAILY` 等其它频率 | ⛔ 按"只上一次"处理并提示 |

### 两个关键设计

1. **学期起始日由文件自己决定**：ICS 里是**绝对日期**，而本项目的周次是"相对学期第 1 周"。
   解析器取"文件里最早一节课所在周的周一"作参考周一，并让导入页用它当学期起始日
   （覆盖"现在是第几周"的推算）—— 否则单双周、结课周会整体错位。
2. **时间 → 节次：区间包含优先**。导出方按它自己的作息导出（例如它 10:00 上课，而本校第 3 节是 09:40），
   所以先把时间落进"哪一节的区间里"，落不进去才取最接近的一节（容差 30 分钟）。
   > 这条规则是**用 Python 镜像同一算法跑样本**才发现的：原先"最近节次 ±15 分钟"会把 10:00 直接判成"认不出节次"。
