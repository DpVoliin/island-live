# 各品牌「通知存活 / 后台保活」设置路径

> 目的：让**上课提醒**和**常驻通知**在你手机上真的留得住 —— 不然一到后台就被清，用户看到的就是
> 「提醒不响」「常驻通知不常驻」。

## 先说应用侧已经做了什么

- **前台服务**（`specialUse` 类型）承载常驻通知 → 通知栏**划不掉**，进程被顶到前台优先级，不易被回收
- **开机广播**自动补回常驻通知与上课提醒（闹钟不跨重启存活，必须重排）
- 侧栏「后台与通知存活」提供三个直达入口：**电池优化**（请求忽略电池优化）、**应用信息**、**通知设置**

## 系统侧还得你手动给一次（一次性，之后长期有效）

### vivo / iQOO（OriginOS / Funtouch）

| 要开 | 路径 |
|---|---|
| 后台高耗电 | 设置 → 电池 → **后台耗电管理** → 本应用 → 允许**后台高耗电** |
| 自启动 | i管家 → 应用管理 → 权限管理 → **自启动** → 本应用打开 |
| 后台运行 | 设置 → 应用与权限 → 权限管理 → 本应用 → **后台运行** 允许 |

> OriginOS 把"能不能常驻"拆成 **后台高耗电** 和 **自启动** 两个开关，只开一个通常还是会被清。

### 小米 / Redmi（HyperOS / MIUI）

- 设置 → 应用设置 → 应用管理 → 本应用 → **自启动** 打开
- 同一页 → **省电策略 → 无限制**
- 最近任务 → 下拉本应用卡片 → 点**锁**图标（防"一键清理"）
- 设置 → 通知与控制中心 → 本应用 → 允许通知 / **在状态栏显示**

### OPPO / 一加 / realme（ColorOS）

- 设置 → 应用 → 应用管理 → 本应用 → **允许自启动** + **允许关联启动** + **允许后台活动**
- 设置 → 电池 → 本应用 → **不优化**

### 荣耀（MagicOS）/ 华为（HarmonyOS）

- 设置 → 应用 → **应用启动管理** → 本应用 → 关掉"自动管理" → 手动打开
  **自启动 / 关联启动 / 后台活动**

### 三星（One UI）

- 设置 → 电池与设备维护 → 电池 → **后台使用限制** → 把本应用加入"**永不休眠的应用**"
- 设置 → 应用 → 本应用 → 电池 → **不受限制**

## 为什么系统侧必须手动

Android 从 6.0 起允许用户/厂商限制后台；从 12 起又限制了后台启动前台服务。
厂商在此基础上加了各自的省电白名单，**没有任何 API 能让应用自己把自己加进白名单** ——
只能引导用户去点。这也是为什么"保活"从来不是纯代码问题。

## 代码层面做了哪些（三条独立复活路径）

厂商的后台限制**没有公开 API、也没有官方文档**（见下"来源"），所以应用侧只能把标准机制用满、并留多条互为兜底的路：

| 路径 | 机制 | 特点 |
|---|---|---|
| ① 闹钟看门狗 | `AlarmManager` 15 分钟 | 独立于 App 进程，到点补回通知 |
| ② JobScheduler 巡检 | `setPersisted(true)` 周期任务 | 标准后台调度，**重启后自动恢复注册** |
| ③ 划掉秒复活 | 通知 `deleteIntent` + 服务 `onTaskRemoved` | 通知被划掉**立刻补回**；任务被划掉 1 秒后重拉服务 |
| ④ 亮屏即补 | 前台服务内注册 `SCREEN_ON` / `USER_PRESENT` | 息屏被清后，亮屏那一下补回 |

通知本身：`setOngoing(true)` + `setAutoCancel(false)` + **前台服务承载** + `deleteIntent` 回补 → 效果就是"**卡在通知栏里**"。
要真正关掉：侧栏「通知」→「关闭通知」（关了之后①②③④都会停）。

## 各厂商用户侧设置（实测资料原文）

来源：**dontkillmyapp.com**（长期维护的各厂商后台限制实测库；vivo / 小米 条目原文引用如下）

### vivo（该站评分 3 💩）
> System restrictions on Vivo phones have not been fully uncovered yet. The apps loading from the background need a special permission for **Autostart**.

- **自启动**：设置 → 更多设置 → 应用 → 自启动（Funtouch OS 2.6 及更早：i 管家 → 应用管理 → 自启动管理）
- **电池不受限制**（Android 13+）：设置 → 该应用 → 电池 → 不受限制
- **后台耗电管理**（Android 13+）：设置 → 电池 → 后台耗电管理
- **锁定任务**：后台任务里上滑该应用 → 点锁头 🔒（原文：locked apps are safe from getting terminated）
- 该站另注：vivo 的限制"尚未被完全摸清"

### 小米 / Redmi（该站评分 5 💩）
> There are **no APIs and no documentation** for those extensions. In default settings, background processing simply does not work right.

- **锁定后台**：最近任务里把卡片**下拉** → 出现锁头 🔒 → 点它（原文：locked/pinned apps will not be cleared from the background, even if you clear recent apps）
- 部分机型在**安全中心 → 优化加速**里还有一层"锁定"
- 另需：设置 → 应用管理 → 该应用 → 自启动（开）+ 省电策略（无限制）

> 注：以上路径随系统版本会变；行文按该站原文整理，**未逐条对照官方文档**（其明确说明厂商未提供文档）。
